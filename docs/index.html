Mail Merge

One sheet, one template. It prepares a personalised message for every row and hands each one to your mail client — and it assembles a report from the same columns, where every figure shows the row it came from.

Messages Dear {{Name}}, your invoice for Rs {{Amount}} is ready. → three rows become three messages, each with its own values. Each opens in your mail client. Nothing is sent from here.

What it does

  • Reads a real CSV — quoted commas, doubled quotes, embedded newlines, CRLF, a BOM.
  • Personalises by column name, so {{Name}} is that column's value and nothing is calculated.
  • Guesses the address column, and lets you change it.
  • Excludes rows with no address or a broken one, and lists each excluded row with its reason.
  • Keeps a per-recipient status on the device: prepared, opened in mail client, marked sent by you.
  • Assembles a report where every figure carries its column, its rows and its file.
  • Remembers a file's columns, and refuses next month's file if the columns do not match.

What it will not do

  • Send anything. There is no transport in this app — no SMTP, no API, no queue. It composes and hands over a mailto: link; your mail client is the sender.
  • Claim a send it did not perform. A fresh batch is only ever "prepared"; "marked sent" is a box you tick.
  • Do arithmetic it cannot show. A placeholder is a column, never an expression — {{Amount * 2}} is refused as a column that does not exist.
  • Merge with a missing column. A placeholder with no matching column refuses the whole merge, by name, rather than producing half-filled messages.
  • Upload anything. No network at runtime; the page's CSP sets connect-src 'none'.

When things go wrong

CaseWhat happens
Bad inputA placeholder with no column is refused by name and the merge does not run. A row with no usable address is excluded and listed.
No networkNothing changes: composing and personalising are local. The app says plainly that it composed the messages and did not send them.
Storage full or unavailableThe output is not written, and the message names how many items had been prepared — so a partial batch is never mistaken for a complete one.
Corrupt saved stateAn unreadable status file is reported and offered for export; the sheet and the template are kept separately, so a broken status cannot lose the source data.

How to run it

  • Here: play/index.html, or install it from your browser's menu.
  • Offline file: open docs/play/index.html straight from disk.
  • Tests: node tests/self-tests.js — every "will not do" above is a named assertion.
